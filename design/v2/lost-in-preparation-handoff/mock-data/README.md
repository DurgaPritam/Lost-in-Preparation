# mock-data/

There is one JSON file for each contract file. They are generated by `npm run mock-data` from the typed mocks in `src/contract/index.ts`, so don't edit them by hand.

All values are placeholders:

- numbers are repeating digits
- study titles are prefixed `[MOCK]`
- PMIDs are `0000000n`
- passages are invented text
- dates are placeholders

`null` means unknown or not stated.

The contract shapes are assumed until the project's JSON Schemas arrive. See HANDOFF.md §0.
